# 기존 6개 지역 가이드 빈칸 채우기 — 수집 체크리스트

작성일 2026-08-25 · 대상 `data/guide/` 지역 파일 6개

---

## 0. 시작 전 원칙 3가지

**① 공통 가이드와 겹치는 내용은 쓰지 않는다.**
검색 시 지역 문서에 배정되는 자리는 **2청크뿐**이다 (`RAG_TOP_K_REGION=2`,
공통 1, 법령 2). 공통 가이드에 이미 있는 "대형폐기물 3단계 절차",
"폐의약품이란" 같은 서술을 지역 파일에 옮겨 적으면 그 2자리를 중복이
차지해서 정작 필요한 지역 정보가 밀려난다. **그 지역만의 채널·요일·조건**만 적는다.

**② 초안은 `data/guide` 밖에 둔다.**
`seed_docs` 는 `_` 로 시작하는 파일을 건너뛰지만,
`RAG_SOURCE=files` 모드의 `_load_from_files()` 에는 그 필터가 **없다**.
초안을 guide 폴더에 두면 files 모드에서 플레이스홀더가 그대로 색인된다.
(`data/laws/README.md` 도 같은 이유로 files 모드에서는 색인된다 — 별건이지만 기록해 둘 것)

**③ 파일명에도 지역 키워드가 들어가야 한다.**
`seed_docs` 는 **제목**에서, files 모드는 **파일명**에서 지역을 뽑는다.
둘 중 하나만 맞으면 모드에 따라 필터가 조용히 빗나간다.
지금은 우연히 15개 모두 일치 상태이므로, 파일명을 바꿀 때 주의한다.

## 2. 항목별 수집처

| 항목 | 1차 출처 | 비고 |
|---|---|---|
| 배출 요일·시간 | 해당 시·군·구청 홈페이지 청소/자원순환 메뉴 | 법적 근거는 지자체 **폐기물 관리 조례** |
| 조례 원문 | 자치법규정보시스템 elis.go.kr | 조례는 2순위 수집 대상이므로 링크만 메모 |
| 대형폐기물 신고 | 구청 홈페이지 또는 위탁 사이트 | 민간 앱(빼기 등)은 보조 채널로만 기재 |
| 폐의약품 우체통 | 지자체 공고 | **지역마다 시행 여부가 갈린다.** 추측 금지 |
| 폐가전 무상수거 | 이미 공통 가이드에 있음 | 지역 파일에는 "공통 가이드 참조"로만 |
| 품목별 요령 | 지자체 분리배출 안내문 | 공통과 같으면 **적지 않는다** |

**서울은 자치구 소관이라 단일 답이 없는 항목이 많다.** 없는 답을 만들지 말고
"자치구마다 다르며 확인 경로는 ○○" 형태로 쓰는 편이 정확하고, 챗봇 답변도 그게 맞다.

## 3. 작성 규칙 (청킹이 여기 의존한다)

```
[지역명] 제목                             ← 첫 줄, "[" 로 시작, 80자 이하
                                          ← 빈 줄
출처: 기관명(주소), 담당부서(전화), 작성 기준일 2026-08-__
지역: seoul                               ← REGION_MAP 값과 정확히 일치

=== 섹션 이름 ===                          ← 청킹 1차 경계

[블록 이름]                                ← 청킹 2차 경계
- 항목
- 항목
```

- 섹션·블록 이름은 기존 파일의 표현을 그대로 쓴다
  (`=== 대형폐기물 배출 ===`, `[신고와 배출]`, `[배출 시간]` 등).
  같은 뜻을 다른 말로 쓰면 지역 간 검색 품질이 들쭉날쭉해진다.
- **작성 기준일을 반드시 남긴다.** 요일·수수료·보조금은 금방 바뀐다.
  현재 서울·천안·부산남구·환경부 4개 파일에 기준일이 없다 — 이번에 같이 채운다.

## 4. 병합 후 절차

```bash
python check_guide_format.py data/guide     # 오류 0건 확인
python manage.py seed_docs --reindex        # 적재 + FAISS 재구축
python evals/run_eval_hybrid.py             # region_specific 문항 점수 확인
```

`check_guide_format.py` 가 잡는 것: 제목 깨짐, 지역 코드 3중 불일치,
섹션 마커 누락, **초안 플레이스홀더 잔존**, 기준일 누락.

병합 전후로 `evals/qa_set.json` 의 `region_specific` 10문항 점수를 비교해
기록해 두면 수집 작업의 효과를 그대로 보여줄 수 있다.

## 5. 주의: 건드리면 안 되는 것

- **지역을 늘리지 않는다.** 이번 작업은 기존 6개 심화다.
  새 지역은 `members/models.py::REGION_CHOICES` 와 `seed_docs.REGION_MAP` 을
  함께 고쳐야 하고 마이그레이션이 발생하며, 평가셋 `q027`(대구 수성구 =
  "자료 없음"이 정답)이 깨진다.
- **`q029`(전기차 폐배터리)** 도 "자료 없음"이 정답이다. 유해폐기물 섹션을
  채울 때 전기차 배터리를 끌어들이지 않는다.
